# NOTEBOOK-PLAN — Pi Agents

This plan belongs to the [PI Agents development repository](../../README.md).
The manuscript is maintained separately; see [the notebook guide](README.md)
for the combined-checkout dependencies that remain after migration.

One row for every numbered chapter and appendix in *Pi Agents*: 42 chapters plus
two appendices, `01-chapter.ipynb` … `44-chapter.ipynb`.

The setup page `run-the-examples.md` and the section page `_index.md` are
supporting pages, not numbered chapters, and have no notebook.

## How to read this table

| Column | Meaning |
|---|---|
| **Question** | The one thing a reader can answer by looking at the notebook's own output. If no output could answer it, the notebook does not do that. |
| **Experiment / inspection** | What the notebook actually does. |
| **Canonical example** | The file under `examples/` that carries the chapter's evidence. `—` means the chapter has no example directory and the notebook says so. |
| **Mode** | **Run** · **Inspect/reproduce** · **Demonstrate** · **Manual/optional live** (see the glossary at the foot). |
| **Dependencies** | What must exist for the default path: `pi-*@1.0.4` in `examples/node_modules`, Node ≥ 22.19, and where noted a POSIX shell or the `git` binary. |
| **Limits** | The claim the notebook deliberately does *not* make. |

**Evidence scope** is the book's own vocabulary: `declarations`,
`in_process_runtime`, `shipped_binary`, `real_model`. This set contains **no
`real_model` evidence**, because the book contains none.

## Glossary: the execution modes

| Mode | What it means here |
|---|---|
| **Run** | The pinned runtime is executed. Either the chapter's own example or a notebook-local driver that calls the same packages and the same harness. The output was produced by this execution, not remembered. |
| **Inspect/reproduce** | Preserved evidence is read and a result derived or re-checked from it. The notebook names the artifact, its version and its provenance, and does not present a recording as a current run. |
| **Demonstrate** | A deterministic illustration of a pattern **this book proposes**, clearly labelled, which does not pretend to prove a Pi contract. Chapter 30 is the only chapter in this category. |
| **Manual/optional live** | Work that needs a terminal, a container, a credential or a real model. It is written as a checklist with prerequisites and is reported **NOT RUN** unless it was actually run. In this set: chapter 2's install, chapter 20's drawing, chapter 42's containers, chapter 44's layers 1–2. |

## What is deliberately absent

* **No `real_model` cells.** The book has no accepted real-model evidence. The
  contract for a future run is frozen in `planning/real-model-plan.md`, and the one
  retained attempt (`examples/real-model/runs/R0/.../ABORTED.md`) produced zero
  tokens. Optional live sections, if a reader writes one, must be explicitly
  enabled, must state their prerequisites and expected cost, and must take
  credentials from the environment — never from a cell.
* **No browser experiences beyond the two that exist.** `programmer.ie` has recorded
  experiences for chapters 31 and 39. Those are reused as *inspected artifacts* by
  notebooks 31 and 39, and are not duplicated 44 times.
* **No notebook for `run-the-examples.md` or `_index.md`.** They are supporting
  pages, not numbered chapters.
